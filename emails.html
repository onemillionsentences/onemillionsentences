How to connect these emails

These templates are fully designed and written. To send them automatically, connect them to one of these email services. All are easy to use and do not require coding experience.

Recommended email sending services

⭐ SendGrid — Best choice (free up to 100/day)
Mailgun — Developer friendly
Postmark — Fastest delivery
Mailchimp — Easy for beginners
Resend — Modern & simple
1

Open a free SendGrid account

Go to sendgrid.com and create a free account. No credit card needed. You get 100 free emails per day which is more than enough to start.

sendgrid.com → Sign Up Free
2

Get your API key

In SendGrid, go to Settings → API Keys → Create API Key. Copy the key and give it to your developer, or paste it into your backend configuration.

Settings → API Keys → Create API Key
3

Give the templates to your developer

Share this file with your developer. Each template has a clear trigger condition. The developer will connect each trigger to the right SendGrid template ID.

7 templates → 7 trigger events in your backend
4

Test every email before launch

Before going live, test each email by triggering it manually. Check that all the placeholder values ([First Name], [Sentence Text], etc.) are replaced correctly with real data.

Test with your own email address first
⚠️ Important: Replace all placeholder values in brackets — [First Name], [Sentence Text], [Display Name], [#000000], [REF_CODE], [Date], [Stripe ID] — with real data from your database before sending. These are variables that your backend will fill in automatically for each member.
